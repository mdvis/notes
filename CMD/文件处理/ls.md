## 最常用的 ls 选项

| 选项   | 含义                      | 常用组合      | 示例      |
| ---- | ----------------------- | --------- | ------- |
| `-l` | 长格式显示（权限、所有者、大小、时间等）    | `ls -l`   | 最常用     |
| `-a` | 显示所有文件（包括 `.` 开头的隐藏文件）  | `ls -a`   |         |
| `-h` | 以人类可读方式显示文件大小（K、M、G）    | `ls -lh`  | 强烈推荐    |
| `-t` | 按修改时间排序（最新文件在最上面）       | `ls -lt`  |         |
| `-r` | 反向排序（和 `-t`、`-S` 等配合使用） | `ls -ltr` | 按时间从旧到新 |
| `-S` | 文件从大到小                  |           |         |
## 其他非常实用的选项

| 选项   | 含义                             | 示例            |
| ---- | ------------------------------ | ------------- |
| `-R` | 递归显示子目录内容                      | `ls -R`       |
| `-d` | 只显示目录本身，不显示里面的内容               | `ls -ld /etc` |
| `-i` | 显示 inode 号                     | `ls -li`      |
| `-s` | 显示占用块数                         | `ls -s`       |
| `-F` | 在目录后加 `/`，可执行文件加 `*`，链接加 `@` 等 | `ls -F`       |
| `-C` | 多列显示（默认就是多列）                   | -             |
| `-1` | 单列显示（一行一个文件）                   | `ls -1`       |
| `-X` | 按文件扩展名排序                       | `ls -X`       |
| `-v` | 按自然版本号排序（1.10 在 1.2 之后）        | `ls -v`       |
| `-Q` | 文件名用双引号包围                      | `ls -Q`       |
## 超级实用组合命令

```bash
# 1. 最常用长格式（推荐设为别名）
ls -lha

# 2. 按时间排序（最新在上面）
ls -lht

# 3. 按时间从旧到新（常用来看日志或备份）
ls -lhtr

# 4. 按大小排序（最大的在上面）
ls -lhS

# 5. 只看目录本身的信息
ls -ld /path/to/dir

# 6. 显示隐藏文件并按时间排序
ls -lath

# 7. 递归显示但只显示目录结构（类似 tree，但不用安装）
ls -R | less
```
