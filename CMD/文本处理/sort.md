`sort` 是 Linux/Unix 中用于对文本文件内容进行排序的核心命令，以下是其最常用选项及实用场景说明：

---

### **一、基础排序选项**
| 选项 | 作用 | 示例 |
|------|------|------|
| `-r` | 反向排序（降序） | `sort -r file.txt` |
| `-n` | 按数值大小排序（默认按字符串字典序） | `sort -n numbers.txt` |
| `-f` | 忽略大小写（将小写视为大写） | `sort -f names.txt` |
| `-u` | 去重输出（仅保留重复行的第一条） | `sort -u data.txt` |

---

### **二、字段处理（关键！）**
| 选项 | 作用 | 示例 |
|------|------|------|
| `-k` | 指定排序字段（列） | `sort -k 2 file.txt`（按第2列排序） |
| `-t` | 指定字段分隔符（默认空格/Tab） | `sort -t ',' -k 2 data.csv`（逗号分隔） |
| `-b` | 忽略字段前导空白 | `sort -b -k 2 file.txt` |

#### ▶ 字段范围示例：
```bash
sort -k 2,3 file.txt   # 按第2列到第3列排序
sort -k 3.2,3.4        # 按第3列的第2-4个字符排序
```

---

### **三、特殊格式排序**
| 选项 | 作用 | 示例 |
|------|------|------|
| `-h` | 人类可读数字排序（如 1K, 2G） | `sort -h sizes.txt` |
| `-M` | 按月份名称排序（Jan, Feb...） | `sort -M months.txt` |
| `-V` | 自然版本号排序（如 v1.2 > v1.10） | `sort -V versions.txt` |

---

### **四、文件操作与性能**
| 选项 | 作用 | 示例 |
|------|------|------|
| `-o` | 将结果写入指定文件（可覆盖原文件） | `sort file.txt -o sorted.txt` |
| `-c` | 检查文件是否已排序（无输出则已排序） | `sort -c data.txt` |
| `--parallel=N` | 并行排序加速（大文件适用） | `sort --parallel=4 huge.log` |
| `-S SIZE` | 指定内存缓冲区大小 | `sort -S 50% huge.log`（使用50%内存） |

---

### **五、实用组合示例**
1. 按第2列数值逆序排序  
   ```bash
   sort -t ',' -k2nr data.csv
   ```

2. 去重并统计出现次数  
   ```bash
   sort file.txt | uniq -c
   ```

3. 按文件大小（人类可读格式）排序  
   ```bash
   ls -lh | sort -hk5   # 第5列为文件大小
   ```

4. 多列排序：先按第1列升序，再按第2列数值降序  
   ```bash
   sort -k1,1 -k2nr data.txt
   ```

---

### **六、注意事项**
1. 默认行为：按整行字符串字典序排序（非数值！）
2. 稳定性：`sort` 默认稳定排序（相同键的行保持原顺序）
3. 语言环境影响：中文排序需设置 `LANG=zh_CN.UTF-8`
4. 临时文件：超大文件排序可用 `-T /path/to/tmp` 指定临时目录

---

### **速查口诀**
> 数值 `-n`，逆序 `-r`，字段 `-k`，分隔 `-t`  
> 去重 `-u`，输出 `-o`，人类可读加 `-h`
