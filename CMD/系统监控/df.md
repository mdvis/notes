# `df` 命令详解

`df`（**d**isk **f**ree）**查看文件系统磁盘空间使用情况**
## 基本语法

```bash
df [选项] [文件或文件系统]
```

---

## 常用选项

|选项|说明|
|---|---|
|`-h`|以人类可读格式显示（KB、MB、GB）|
|`-T`|显示文件系统类型|
|`-i`|显示 inode 使用情况（而非块使用）|
|`-a`|显示所有文件系统（包括伪文件系统）|
|`-t <类型>`|只显示指定类型的文件系统|
|`-x <类型>`|排除指定类型的文件系统|
|`-k`|以 KB 为单位显示（默认）|
|`-m`|以 MB 为单位显示|
|`-B <大小>`|指定块大小，如 `-B 1M`|
|`--total`|显示总计行|
|`-l`|只显示本地文件系统|

---

## 常用示例

### 1. 查看所有磁盘使用情况（最常用）

```bash
df -h
```

输出示例：

```
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda1        50G   20G   28G  42% /
/dev/sda2       200G  150G   40G  79% /home
tmpfs           3.9G     0  3.9G   0% /dev/shm
```

### 2. 查看文件系统类型

```bash
df -hT
```

输出示例：

```
Filesystem     Type      Size  Used Avail Use% Mounted on
/dev/sda1      ext4       50G   20G   28G  42% /
/dev/sda2      xfs       200G  150G   40G  79% /home
```

### 3. 查看某个目录所在分区的使用情况

```bash
df -h /home
```

### 4. 查看 inode 使用情况

```bash
df -ih
```

> 当磁盘空间充足但无法写入文件时，可能是 inode 耗尽了。

### 5. 只显示 ext4 类型

```bash
df -ht ext4
```

### 6. 排除 tmpfs 等虚拟文件系统

```bash
df -h -x tmpfs -x devtmpfs
```

### 7. 显示总计

```bash
df -h --total
```

---

## 输出字段说明

|字段|含义|
|---|---|
|**Filesystem**|文件系统/设备名|
|**Size**|总容量|
|**Used**|已使用空间|
|**Avail**|可用空间|
|**Use%**|使用百分比|
|**Mounted on**|挂载点|

## 实用技巧

### 🔍 快速找到磁盘满的分区

```bash
df -h | awk '$5+0 > 80 {print $0}'
```

> 筛选使用率超过 80% 的分区。

### 🔍 配合 `du` 定位大文件

```bash
# 先看哪个分区满了
df -h
# 再看该分区下哪个目录占空间大
du -sh /* 2>/dev/null | sort -rh | head -10
```

### 🔍 监控脚本中使用

```bash
usage=$(df / | awk 'NR==2 {print $5}' | tr -d '%')
if [ "$usage" -gt 90 ]; then
    echo "警告：根分区使用率已达 ${usage}%"
fi
```

---

## 与 `du` 的区别

||`df`|`du`|
|---|---|---|
|视角|**文件系统级别**（从超级块读取）|**目录/文件级别**（遍历文件树）|
|速度|快|慢（需遍历）|
|用途|查看分区整体使用情况|查看某个目录占了多少空间|

> ⚠️ 有时 `df` 和 `du` 结果不一致，常见原因：已删除但被进程占用的文件（`df` 仍计入，`du` 不计入）。
