# `df` 命令详解

`df`（disk free）查看文件系统磁盘空间使用情况
```bash
df [选项] [文件或文件系统]
```
## 常用选项

| 选项        | 说明                   |
| --------- | -------------------- |
| `-h`      | 以人类可读格式显示（KB、MB、GB）  |
| `-a`      | 显示所有文件系统（包括伪文件系统）    |
| `-T`      | 显示文件系统类型             |
| `-i`      | 显示 inode 使用情况（而非块使用） |
| `-t <类型>` | 只显示指定类型的文件系统         |
| `-x <类型>` | 排除指定类型的文件系统          |
| `-k`      | 以 KB 为单位显示（默认）       |
| `-m`      | 以 MB 为单位显示           |
| `-B <大小>` | 指定块大小，如 `-B 1M`      |
| `--total` | 显示总计行                |
| `-l`      | 只显示本地文件系统            |

**常见诡异现象**：有时候 `df -h` 显示磁盘已经 100% 满了，但用 `du -sh /*` 统计所有目录加起来却远不到 100%。  
**原因**：通常是因为有**已经被删除但进程仍在占用的文件**（比如正在写入的旧日志文件）。`du` 看不到已删除的文件，但 `df` 认为空间仍被进程占用。解决办法是重启相关服务或重启系统释放文件句柄。
