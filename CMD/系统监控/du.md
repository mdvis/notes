**`du`**（**D**isk **U**sage 的缩写）**查看文件和目录的磁盘空间占用情况**。
### 1. 基本语法

```bash
du [选项] [文件或目录...]
```

_如果不指定任何路径，`du` 默认会递归统计当前目录下所有子目录的大小。_

---

### 2. 最常用的选项（参数）

|选项|全称|说明|
|:--|:--|:--|
|**`-h`**|`--human-readable`|**最常用**。以人类易读的格式显示大小（如 K, M, G），而不是默认的字节/块数。|
|**`-s`**|`--summarize`|仅显示目标目录的**总大小**，不列出其内部子目录的详细情况。|
|**`-a`**|`--all`|显示目录中**所有文件**和子目录的大小（默认只显示目录的大小）。|
|**`-c`**|`--total`|在输出的最后一行显示所有统计项的**总和**。|
|**`-d <N>`**|`--max-depth=<N>`|限制目录遍历的深度。例如 `-d 1` 或 `-d 0`（等同于 `-s`）。|
|**`--exclude=<模式>`**|-|排除符合特定模式的文件或目录（如 `--exclude="*.log"`）。|

---

### 3. 日常高频使用场景与示例

#### 场景一：查看某个目录的总大小

如果你只想知道一个文件夹总共占了多大空间，不想看里面乱七八糟的子目录：

```bash
du -sh /var/log
# 输出示例: 1.2G  /var/log
```

#### 场景二：查看当前目录下各个子文件夹的大小（深度为1）

这是排查“哪个文件夹占用了空间”时**最实用**的命令：

```bash
du -h --max-depth=1
# 或者简写为：
du -h -d 1
```

_(注：如果想包含当前目录下的普通文件，可以使用 `du -sh *`)_

#### 场景三：找出当前目录下占用空间最大的前 10 个文件/目录

结合 `sort` 和 `head` 命令，可以快速揪出“空间刺客”：

```bash
du -sh * | sort -hr | head -n 10
```

_解释：`-h` 输出带单位的格式，`sort -hr` 按照人类可读的数字大小进行降序排列，`head -n 10` 取前 10 行。_

#### 场景四：统计某个目录下所有 `.log` 文件的总大小

结合 `find` 命令使用：

```bash
find /var/log -name "*.log" -exec du -ch {} + | grep total
```

#### 场景五：排除某些特定的目录

比如在统计网站目录大小时，不想把 `node_modules` 或 `cache` 算进去：

```bash
du -sh --exclude="node_modules" /var/www/html
```

### 4. 💡 进阶提示：`du` 与 `df` 的区别

很多初学者会把 `du` 和 `df` 搞混，它们的用途完全不同：

- **`du` (Disk Usage)**：从**文件层面**自下而上统计。它遍历你指定的目录，把里面每个文件的大小加起来。**用于排查“具体是哪个文件/文件夹占用了空间”。**
- **`df` (Disk Free)**：从**文件系统层面**查看。它直接读取磁盘分区的元数据，告诉你整个硬盘或分区还剩多少空间。**用于排查“硬盘是不是快满了”。**

**常见诡异现象**：有时候 `df -h` 显示磁盘已经 100% 满了，但用 `du -sh /*` 统计所有目录加起来却远不到 100%。  
**原因**：通常是因为有**已经被删除但进程仍在占用的文件**（比如正在写入的旧日志文件）。`du` 看不到已删除的文件，但 `df` 认为空间仍被进程占用。解决办法是重启相关服务或重启系统释放文件句柄。
