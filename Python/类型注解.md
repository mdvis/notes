**Python 类型注解（Type Annotations / Type Hints）全面讲解**

Python 从 **3.5** 版本引入类型注解（PEP 484），它**不是强制运行时检查**，而是为开发者、IDE 和静态类型检查工具（如 mypy、pyright、pylance）提供类型信息，帮助提升代码可读性、可维护性和早期发现错误。

### 1. 基本语法

在变量、函数参数、返回值后面用 `:` 和 `->` 标注类型。

```python
# 变量注解（Python 3.6+ 支持）
name: str = "张三"
age: int = 25
score: float = 95.5
is_active: bool = True
data: dict = {}          # 不推荐，建议写明泛型

# 函数注解
def add(a: int, b: int) -> int:
    return a + b

# 多个返回值（使用 tuple）
def divmod_ext(a: int, b: int) -> tuple[int, int]:
    return divmod(a, b)
```

**注意**：
- 注解是**元数据**，运行时不影响性能（除非使用 `typing.get_type_hints`）。
- Python 3.10+ 支持 `|` 表示 Union（例如 `int | None`）。

### 2. 常用内置类型

| 类型          | 注解写法（Python 3.9+）       | 旧 typing 写法（兼容旧版本）          | 说明 |
|---------------|-------------------------------|-------------------------------------|------|
| 整数          | `int`                         | `int`                               | - |
| 浮点数        | `float`                       | `float`                             | - |
| 布尔          | `bool`                        | `bool`                              | - |
| 字符串        | `str`                         | `str`                               | - |
| 字节          | `bytes`, `bytearray`          | 同左                                | - |
| None          | `None` 或 `NoneType`          | `None`                              | - |
| 任意类型      | `Any`                         | `typing.Any`                        | 禁用类型检查 |
| 无返回值      | `None`                        | `None`                              | 函数返回 `None` |

**集合类型（推荐 3.9+ 写法）**：

```python
from collections.abc import Iterable, Sequence, Mapping

# 列表
numbers: list[int] = [1, 2, 3]

# 字典
user: dict[str, int] = {"age": 18, "score": 95}

# 元组（固定长度）
point: tuple[int, int] = (10, 20)

# 可变长度元组
coords: tuple[float, ...] = (1.5, 2.5, 3.0)

# 集合
unique_ids: set[int] = {1, 2, 3}

# 冻结集合
frozen: frozenset[str] = frozenset(["a", "b"])
```

### 3. Optional 与 Union

```python
from typing import Optional, Union

# Optional 等价于 X | None
age: Optional[int] = None          # Python 3.10+ 推荐写 age: int | None = None

# Union 多类型
result: Union[int, float, None] = None
# 3.10+ 写法
result: int | float | None = None
```

### 4. 特殊类型

```python
from typing import Any, NoReturn, Never, Literal, Final

def process(data: Any) -> None: ...          # 任意类型

def infinite_loop() -> NoReturn:             # 永不返回（抛异常或死循环）
    while True:
        pass

status: Literal["success", "error", "pending"] = "success"

MAX_SIZE: Final[int] = 100                   # 不可重新赋值（mypy 检查）
```

### 5. 泛型（Generics）

```python
from typing import TypeVar, Generic

T = TypeVar("T")      # 声明类型变量

class Box(Generic[T]):
    def __init__(self, item: T):
        self.item = item
    
    def get(self) -> T:
        return self.item

# 使用
int_box: Box[int] = Box(42)
str_box: Box[str] = Box("hello")
```

**带约束的 TypeVar**：

```python
T = TypeVar("T", int, float)        # 只能是 int 或 float
S = TypeVar("S", bound=str)         # 必须是 str 的子类
```

### 6. TypedDict（结构化字典）

```python
from typing import TypedDict

class UserInfo(TypedDict):
    name: str
    age: int
    tags: list[str] | None

user: UserInfo = {"name": "李四", "age": 30, "tags": ["vip"]}
```

**Total=False**（可选字段）：

```python
class PartialUser(TypedDict, total=False):
    name: str
    age: int
```

### 7. Protocol（鸭子类型 / 结构子类型）

```python
from typing import Protocol

class SupportsClose(Protocol):
    def close(self) -> None: ...

def close_resource(res: SupportsClose) -> None:
    res.close()
```

### 8. 类中的类型注解

```python
class Student:
    name: str                     # 类变量/实例变量注解
    age: int
    
    def __init__(self, name: str, age: int) -> None:
        self.name = name
        self.age = age
    
    def greet(self) -> str:
        return f"Hi, {self.name}"
```

**Self**（Python 3.11+）：

```python
from typing import Self

class Tree:
    def add_child(self, child: Self) -> Self:
        ...
        return self
```

### 9. 回调函数 / Callable

```python
from collections.abc import Callable

def apply(func: Callable[[int, str], bool], x: int, y: str) -> bool:
    return func(x, y)

# 例子
def checker(a: int, b: str) -> bool:
    return len(b) > a
```

### 10. 类型别名（Type Alias）

```python
# Python 3.10+
type Matrix = list[list[float]]

# 旧写法
Matrix = list[list[float]]
```

### 11. 实战综合示例

```python
from collections.abc import Iterable
from typing import Optional, Literal

type JsonValue = str | int | float | bool | None | list['JsonValue'] | dict[str, 'JsonValue']

def process_data(
    items: Iterable[dict[str, JsonValue]],
    mode: Literal["strict", "lenient"] = "strict"
) -> list[int]:
    result: list[int] = []
    for item in items:
        value = item.get("score")
        if isinstance(value, (int, float)):
            result.append(int(value))
        elif mode == "lenient":
            result.append(0)
    return result
```

### 12. 常用工具与最佳实践

1. **静态检查工具**：
   - `mypy`（最成熟）
   - `pyright` / VSCode Pylance（速度快）
   - `pytype`

   安装：`pip install mypy`

   使用：`mypy your_script.py --strict`

2. **运行时获取注解**：
   ```python
   import typing
   typing.get_type_hints(your_function)
   ```

3. **最佳实践**：
   - 公共 API 必须加类型注解。
   - 内部简单函数可省略。
   - 使用 `typing.cast` 必要时进行类型转换。
   - 避免过度使用 `Any`。
   - 优先使用 `collections.abc` 中的抽象基类（`Iterable`、`Mapping` 等）而非具体类型。
   - Python 3.9+ 优先使用内置泛型（`list[int]` 而非 `List[int]`）。

### 13. 版本兼容总结

- **Python 3.9+**：内置泛型 `list[int]`、`dict[str, int]`。
- **Python 3.10+**：`|` 语法、`match` 支持类型。
- **Python 3.11+**：`Self`、`typing.Never` 等。
- **Python 3.12+**：类型别名 `type` 关键字更强大。

**推荐学习路径**：
1. 阅读官方文档：https://docs.python.org/3/library/typing.html
2. 实战项目中逐步添加类型。
3. 用 `mypy --strict` 强制检查整个项目。
