`git branch` 是管理本地分支的核心命令，常用选项分类如下：
### 1️⃣ 查看分支
| 选项                     | 说明                                       |
| ---------------------- | ---------------------------------------- |
| `(无)`                  | 列出本地分支，当前分支用 `*` 标记                      |
| `-r`                   | 列出**远程跟踪分支**（如 `origin/main`）            |
| `-a`                   | 列出**所有分支**（本地 + 远程）                      |
| `-v`                   | 显示每个分支的**最新提交哈希和提交信息**                   |
| `-vv`                  | 显示本地分支与其**跟踪的远程分支的差异**（领先/落后计数）          |
| `--merged [commit]`    | 列出已合并到当前分支（或指定 `commit`）的分支              |
| `--no-merged [commit]` | 列出未合并到当前分支（或指定 `commit`）的分支              |
| `--contains <commit>`  | 列出包含指定提交的分支                              |
| `--sort=<key>`         | 按条件排序（如 `--sort=-committerdate` 按最近提交排序） |
### 2️⃣ 创建/重命名/删除分支
| 选项                                   | 说明                                           |
| ------------------------------------ | -------------------------------------------- |
| `<branch>`                           | 直接创建新分支（基于当前 HEAD）                           |
| `-c <old> <new>`<br>`-C <old> <new>` | 复制分支（`-C` 强制覆盖已存在分支）                         |
| `-m <old> <new>`<br>`-M <old> <new>` | 重命名分支（`-M` 强制覆盖）                             |
| `-d <branch>`<br>`-D <branch>`       | 删除分支（`-D` 强制删除未合并的分支）                        |
| `--delete --remotes` 或 `-d -r`       | 删除远程跟踪分支（如 `git branch -d -r origin/branch`） |
| `-u <remote>/<branch>`               | 设置本地分支的上游（跟踪分支）                              |
| `--unset-upstream`                   | 移除已设置的上游跟踪关系                                 |
### 3️⃣ 其他实用选项
| 选项               | 说明                                       |
| ---------------- | ---------------------------------------- |
| `--list` 或 `-l`  | 显式列出分支（常与通配符 `--list "fix-*"` 一起使用）      |
| `--show-current` | 输出当前分支的名称                                |
| `-f <branch>`    | 强制移动分支（`-f` 可与 `-c`/`-m`/`-C`/`-M` 结合使用） |
| `--format`       | 自定义输出格式（如 `--format='%(refname:short)'`） |
### 📌 常用组合示例
```bash
git branch -a            # 所有分支（本地+远程）
git branch -vv           # 查看跟踪关系及落后/领先情况
git branch --merged      # 查看已合并的分支（可安全删除）
git branch -d old-feature # 删除已合并的分支
git branch -D junk        # 强制删除未合并的分支
git branch -m main master # 重命名当前分支为 master
git branch -u origin/main # 让当前分支跟踪 origin/main
```
