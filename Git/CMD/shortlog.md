`git shortlog` 专门用于按作者聚合提交，是做贡献者统计的最简方式。

| 选项                 | 作用                                   | 示例                                      |
| -------------------- | -------------------------------------- | ----------------------------------------- |
| `-s` / `--summary`   | 只输出**提交计数**，不显示详细提交信息 | `git shortlog -sn`                        |
| `-n` / `--numbered`  | 按提交数**从多到少排序**               |                                           |
| `-e` / `--email`     | 同时显示作者邮箱                       | `git shortlog -sne`                       |
| `--no-merges`        | 排除 merge commit                      |                                           |
| `--since=<date>`     | 同 `git log`，支持时间过滤             | `git shortlog -sn --since="6 months ago"` |
| `-c` / `--committer` | 按**提交者**而非作者分组               |                                           |

> **作者 vs 提交者：** 作者 = 写代码的人；提交者 = 执行 commit 操作的人。个人项目两者相同，团队中可能有差异（如通过 PR 合并时）。
