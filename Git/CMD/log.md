### 1. 输出格式控制

| 选项               | 作用                                        | 示例                                    |
| ------------------ | ------------------------------------------- | --------------------------------------- |
| `--format=<fmt>`   | 自定义输出格式，`format:` 表示空字符串      | `--format=format:` 输出空行，只留文件名 |
| `--format='%ad'`   | 输出作者日期                                | 配合 `--date` 格式化                    |
| `--format='%H'`    | 输出完整 commit hash                        |                                         |
| `--format='%an'`   | 输出作者名                                  |                                         |
| `--format='%s'`    | 输出提交标题                                |                                         |
| `--oneline`        | 等价于 `--format='%h %s'`，一行一条         | 常配合 `grep` 筛选                      |
| `--pretty=<style>` | 预设格式：`oneline`/`short`/`full`/`medium` | `--pretty=oneline`                      |

> **常用占位符速查：**
>
> - `%H` 完整 hash · `%h` 短 hash
> - `%an` 作者名 · `%ae` 作者邮箱 · `%cn` 提交者名
> - `%ad` 作者日期 · `%cd` 提交者日期 · `%ar` 相对时间
> - `%s` 提交标题 · `%b` 提交正文
> - `%d` 分支/标签引用

### 2. 文件信息

| 选项            | 作用                                                                |
| --------------- | ------------------------------------------------------------------- |
| `--name-only`   | 每条提交后列出**被修改的文件名**（仅文件名）                        |
| `--name-status` | 列出文件名**并标注操作类型**：`A`=新增 `M`=修改 `D`=删除 `R`=重命名 |
| `--stat`        | 显示每个文件的**增删行数统计**                                      |
| `--numstat`     | 以数字形式显示增删行数（适合脚本处理）                              |

### 3. 时间过滤

| 选项                                 | 作用                         | 示例                                                                    |
| ------------------------------------ | ---------------------------- | ----------------------------------------------------------------------- |
| `--since=<date>` / `--after=<date>`  | 只显示**指定时间之后**的提交 | `--since="1 year ago"`、`--since="2024-01-01"`、`--since="2 weeks ago"` |
| `--until=<date>` / `--before=<date>` | 只显示**指定时间之前**的提交 | `--until="2024-06-30"`                                                  |
| `--date=format:'%Y-%m'`              | 自定义日期**输出格式**       | `--date=format:'%Y-%m-%d %H:%M'`                                        |

> 支持的自然语言时间：`"yesterday"`、`"1 month ago"`、`"2 weeks ago"`、`"last monday"` 等。

### 4. 提交信息过滤

| 选项                 | 作用                                         | 示例                        |
| -------------------- | -------------------------------------------- | --------------------------- | ---------------------- |
| `--grep=<pattern>`   | 按**提交信息**正则筛选                       | `--grep="fix\|bug\|broken"` |
| `-i`                 | 忽略大小写（对 `--grep`、`--author` 均生效） | `--grep="FIX" -i`           |
| `-E`                 | 使用**扩展正则**（`                          | `、`+`、`?` 无需转义）      | `--grep="fix\|bug" -E` |
| `--author=<name>`    | 按**作者**筛选                               | `--author="张三"`           |
| `--committer=<name>` | 按**提交者**筛选                             |                             |
| `--invert-grep`      | 反向匹配（排除符合 `--grep` 的提交）         |                             |

> **`-E` 与不加 `-E` 的区别：**
>
> - 不加 `-E`：基础正则，`|` 需转义为 `\|`
> - 加 `-E`：扩展正则，`|` 直接使用

### 5. 其他常用过滤

| 选项                         | 作用                                     |
| ---------------------------- | ---------------------------------------- |
| `--no-merges`                | 排除 merge commit                        |
| `--merges`                   | 只看 merge commit                        |
| `-n <N>` / `--max-count=<N>` | 限制输出条数                             |
| `--all`                      | 搜索所有分支                             |
| `<branch>`                   | 指定分支，如 `git log main`              |
| `<since>..<until>`           | 指定区间，如 `git log v1.0..v2.0`        |
| `-- <path>`                  | 只看指定路径的变更，如 `git log -- src/` |
