| 功能            | Windows/Linux    | macOS           | 备注                     |
| --------------- | ---------------- | --------------- | ------------------------ |
| 命令面板        | Ctrl + Shift + P | Cmd + Shift + P | 万能键，可执行任何命令   |
| 快速打开文件    | Ctrl + P         | Cmd + P         | 快速搜索文件名并打开     |
| 侧边栏开关      | Ctrl + B         | Cmd + B         | 增大代码可视面积         |
| 调出/隐藏终端   | Ctrl + `         | Cmd + `         | 快速查看命令行           |
| 全局搜索        | Ctrl + Shift + F | Cmd + Shift + F | 在所有文件中查找         |
| 选中当前单词    | Ctrl + D         | Cmd + D         | 连按可选中下一个相同的词 |
| 选中所有相同词  | Ctrl + Shift + L | Cmd + Shift + L | 一次性修改所有同名变量   |
| 手动添加光标    | Alt + 点击       | Opt + 点击      | 在任意位置同时编辑       |
| 文件资源管理器  | Ctrl + Shift + E | Cmd + Shift + E | 焦点回到左侧文件树       |
| 源代码管理(Git) | Ctrl + Shift + G | Cmd + Shift + G | 查看 Git 更改            |
| 扩展(插件)面板  | Ctrl + Shift + X | Cmd + Shift + X | -                        |
