## 一些道理

- 摆脱焦虑，远离愤怒。**焦点应该放在控制自己的情绪上**，而不是影响你情绪的人身上
- 焦虑并不能真正帮助我们接近未来。更重要的是，在你**当下所能看到的边界之内**，做一个对得起自己的选择；至于剩下的部分，就交给时间。
- **万事先开头**：切忌完美主义，降低期待
- **聚焦**：一年一个核心，一天一 个核心
- **目标**：目标合理，明确可执行。易完成，正向反馈,培养自信心和成就感
- **帕累托法则**：集中精力做投入最小，效果最好的事。这些高杠杆活动称为“关键的少数”。学会给事情加杠杆，关键部分是少数决定，80% 结果源于 20% 努力
- **刻意练习**：任何领域，刻意练习都是造就顶尖人才的方法，也是顶尖人才保持领先地位的方法。如果你想成为专业人士，刻意训练自己是绝对必不可少的



## 学习方法

| 支柱     | 核心机制                 | 实践关键词                     |                                                                                                                                                                                                        |
| -------- | ------------------------ | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 注意     | 筛选信息，分配大脑带宽   | 专注模式、番茄钟、抑制干扰     |                                                                                                                                                                                                        |
| 主动参与 | 建立深层神经连接         | 深度加工、费曼技巧、主动回想   | **拒绝“虚假学习”：** 下次看书时，每读完一章，合上书尝试用自己的话写出三个要点（主动提取 + 深度加工）。<br/>**费曼学习法**：把一件事讲给别人听才算懂<br/>**反向费曼法**：先听别人讲，然后拆解并重建理解 |
| 错误反馈 | 基于预测误差调整参数     | 贝叶斯模型、刻意练习、及时反馈 | 拥抱“错误”： 考试和自测不是为了证明你有多笨，而是为了给大脑提供预测误差，这是调整突触参数的唯一信号。                                                                                                  |
| 巩固     | 将临时信号转化为物理结构 | 间隔重复、睡眠、自动化         | 利用“生物本能”： 如果一个知识点怎么都记不住，不要熬夜硬背。先大致梳理，然后去睡觉，让大脑在 睡眠 中帮你自动完成突触的修剪与加固。                                                                      |

## 大项目如何推进

- 记录每天的进展，遇到的问题，以及这些问题的进展
- 没有人能记住如此多的问题和细节，所以必须追踪记录
- 记录也让工作进度和内容透明，如果项目不能如期完成，也能知道问题在哪里
- 如果没有项目文档，无法解释项目进展和问题
- 安排工作计划
- 每天至少完成一件事情
- 不要完全放弃有长期收益的事情(解决性能问题、自动化某操作、提高监控覆盖率等)
