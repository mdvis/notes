# 前端开发常用算法（业务 + 面试）

前端开发中涉及的算法可以分为两大维度：**业务实际使用**与**面试考查**。两者重合度较高，但侧重不同。

- **业务常用**：防抖节流、深拷贝、树形互转、排序查找、缓存优化、虚拟 DOM 等
- **面试重点**：动态规划、回溯、手写底层（Promise、diff、排序）、复杂链表等

下文按算法类别分类整理，并标注业务使用频率（★）与面试频率（★）。

## 十五、学习优先级建议

1. **先吃透业务高频**：防抖节流、深拷贝、树形互转、Promise、事件循环 —— 日常开发与面试双高频
2. **掌握手写底层**：Promise A+、虚拟 DOM diff、快速排序、LRU —— 大厂面试必考
3. **补齐面试专项**：动态规划、回溯、图算法 —— 业务少用但面试高频
4. **进阶研究**：Trie、KMP、布隆过滤器、并查集 —— 拔高与差异化竞争力
