以下是 `ls` 命令在 Linux / macOS / Unix 系统中最常用、最实用的选项整理（按使用频率排序）：

### 1. 最常用的 ls 选项（几乎每天都会用到）

| 选项 | 含义                                     | 常用组合  | 示例           |
| ---- | ---------------------------------------- | --------- | -------------- |
| `-l` | 长格式显示（权限、所有者、大小、时间等） | `ls -l`   | 最常用         |
| `-a` | 显示所有文件（包括 `.` 开头的隐藏文件）  | `ls -a`   |                |
| `-h` | 以人类可读方式显示文件大小（K、M、G）    | `ls -lh`  | 强烈推荐       |
| `-t` | 按修改时间排序（最新文件在最上面）       | `ls -lt`  |                |
| `-r` | 反向排序（和 `-t`、`-S` 等配合使用）     | `ls -ltr` | 按时间从旧到新 |

**最推荐的日常组合：**

```bash
ls -lha          # 长格式 + 隐藏文件 + 人类可读大小（最常用）
ls -lhtr         # 按时间从旧到新排序（看最近改了什么文件）
ls -lhS          # 按文件大小从大到小排序
```

### 2. 其他非常实用的选项

| 选项 | 含义                                            | 示例          |
| ---- | ----------------------------------------------- | ------------- |
| `-R` | 递归显示子目录内容                              | `ls -R`       |
| `-d` | 只显示目录本身，不显示里面的内容                | `ls -ld /etc` |
| `-i` | 显示 inode 号                                   | `ls -li`      |
| `-s` | 显示占用块数                                    | `ls -s`       |
| `-F` | 在目录后加 `/`，可执行文件加 `*`，链接加 `@` 等 | `ls -F`       |
| `-C` | 多列显示（默认就是多列）                        | -             |
| `-1` | 单列显示（一行一个文件）                        | `ls -1`       |
| `-X` | 按文件扩展名排序                                | `ls -X`       |
| `-v` | 按自然版本号排序（1.10 在 1.2 之后）            | `ls -v`       |
| `-Q` | 文件名用双引号包围                              | `ls -Q`       |

### 3. 超级实用组合命令（建议记下来）

```bash
# 1. 最常用长格式（推荐设为别名）
ls -lha

# 2. 按时间排序（最新在上面）
ls -lht

# 3. 按时间从旧到新（常用来看日志或备份）
ls -lhtr

# 4. 按大小排序（最大的在上面）
ls -lhS

# 5. 只看目录本身的信息
ls -ld /path/to/dir

# 6. 显示隐藏文件并按时间排序
ls -lath

# 7. 递归显示但只显示目录结构（类似 tree，但不用安装）
ls -R | less
```

### 4. 推荐设置别名（~/.bashrc 或 ~/.zshrc 中添加）

```bash
alias ll='ls -lh'
alias la='ls -lha'
alias lt='ls -lhtr'     # 按时间从旧到新
alias lS='ls -lhS'      # 按大小排序
alias l='ls -CF'
```

### 5. 颜色显示（几乎所有现代系统默认开启）

```bash
ls --color=auto     # 手动开启颜色
```

不同类型文件会有不同颜色：

- 目录：蓝色
- 可执行文件：绿色
- 压缩包：红色
- 链接：青色
- 普通文件：白色
