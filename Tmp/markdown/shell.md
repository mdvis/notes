### 主要结构与核心内容

#### 1. Shell 引号机制

- **单引号 `'...'`**：强引用，所有字符保持字面值。
- **双引号 `"..."`**：弱引用，允许变量/命令扩展。
- **ANSI-C 引号 `$'...'`**：支持转义序列（如 `\n`、`\t`、`\uXXXX`、`\xHH` 等），常用于处理特殊字符（如 URL 中的 `!`）。
- **本地化字符串 `$"..."`**：支持国际化翻译（较少用）。

**应用**：安全处理特殊字符、构造多行字符串、插入控制字符等。

#### 2. Shell 历史扩展（History Expansion）与选项控制

- **历史扩展语法**：`!!`（上一条）、`!string`、`!$`（最后一个参数）、`^old^new` 等。
- **控制方式**：
  - `set +H` / `set -H`：临时关闭/开启历史扩展（解决 `!` 被误解释的问题）。
  - `shopt -s histverify` 等配置可提升安全性。
- 常用 `set` 选项：`-e`（出错退出）、`-u`（未定义变量报错）、`-x`（调试）等。

#### 3. Shell 知识体系分类

- **语法层**：词法/语法/语义分析。
- **引号与扩展层**：扩展执行顺序（花括号 → 波浪号 → 参数 → 命令替换 → 算术 → 进程替换 → 单词拆分 → 文件名扩展）。
- **交互功能层**：命令编辑、补全、历史、作业控制。
- **脚本编程层**：控制结构、函数、信号处理（`trap`）。

#### 4. bash vs sh（POSIX sh）详细对比

- **bash 优势**：数组、关联数组、字符串操作、`[[ ]]`、`process substitution`、花括号扩展等，功能强大，适合复杂脚本。
- **sh 优势**：轻量、可移植、启动快、内存小，适合系统脚本、容器、启动脚本。
- **性能**：sh（尤其是 dash）启动更快、占用更低。
- **推荐脚本头**：
  - 系统/可移植脚本：`#!/bin/sh`
  - 个人/复杂脚本：`#!/usr/bin/env bash`

#### 5. 最佳实践与学习路径

- **选择原则**：系统启动/容器用 sh；个人工具用 bash；跨平台严格用 sh + ShellCheck 检查。
