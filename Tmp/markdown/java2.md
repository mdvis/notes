Java 的知识体系非常庞大，从基础语法到高并发、微服务架构，每一块都需要扎实掌握。为了让你能清晰、系统地复习或学习，我将整个 Java 体系整理成了一个核心知识清单。

我们可以把 Java 的学习分为五个核心阶段，你可以根据自己目前的水平对号入座。

---

## 🚀 Java 核心知识图谱

| 阶段            | 核心模块                | 必须掌握的关键技术点                                                                                                         |
| --------------- | ----------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **1. 基础扎实** | **语法与面向对象**      | 数据类型、访问权限、面向对象三大特性（封装/继承/多态）、接口与抽象类、异常处理机制、泛型。                                   |
|                 | **核心类库**            | String/StringBuilder 的底层原理（常量池）、Java 集合框架（`HashMap`、`ArrayList`、`LinkedList` 的底层结构与扩容机制）。      |
| **2. 进阶必备** | **Java 并发编程 (JUC)** | 线程生命周期、`synchronized` 锁升级、`ReentrantLock`、CAS 与 AQS 体系、线程池的 7 大核心参数、`ThreadLocal` 原理。           |
|                 | **JVM 虚拟机原理**      | JVM 内存区域划分（堆、栈、方法区）、垃圾回收算法（CMS、G1、ZGC）、类加载机制（双亲委派模型）、常见 JVM 调优参数与 OOM 排查。 |
| **3. 生态框架** | **框架核心 (SSM)**      | **Spring**：IoC 容器原理（Bean 的生命周期、循环依赖如何解决）、AOP 原理（动态代理）。<br>                                    |

<br>**Spring Boot**：自动装配原理（`@EnableAutoConfiguration`）。<br>

<br>**MyBatis**：二级缓存机制、延迟加载、动态 SQL。 |
| **4. 微服务架构** | **Spring Cloud 生态** | **微服务组件**：网关（Gateway）、注册与配置中心（Nacos/Consul）、服务调用（OpenFeign）、限流降级（Sentinel）。<br>

<br>**分布式核心**：分布式事务（Seata 理论与模式）、分布式锁（Redisson 实现原理）。 |
| **5. 性能与底座** | **中间件与数据库** | **MySQL**：InnoDB 索引原理（B+树）、事务隔离级别与 MVCC、SQL 优化。<br>

<br>**Redis**：5 种基本数据类型底层结构、持久化（RDB/AOF）、缓存雪崩/击穿/穿透解决方案、集群架构。<br>

<br>**MQ**：RocketMQ/Kafka 的高吞吐架构、消息丢失与幂等性处理。 |

---

> 💡 **避坑提示：**
> 很多初学者容易陷入“只看书、不敲代码”或者“死记硬背框架配置”的误区。Java 框架更新极快，但**底层的 JVM、并发编程和数据库索引原理**是十几年不变的。把底层吃透，看新框架就像看老朋友换件衣服一样简单。
