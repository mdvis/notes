### 文章核心主旨

作者在疫情后成为“末日生存灰人”（低调实用、不张扬的生存主义者），参考以下资料构建个人应急装备体系：

- 应急管理部《基础版家庭应急物资储备建议清单》
- 《怀斯曼生存手册》
- 《户外生存图鉴》
- 其他博主分享经验

主要准备两套装备，均按**广东省/湖南省72小时城市应急标准**设计，适用于地震、火灾、台风、疫情、战争等突发场景：

- **家用 BOB**（Bug Out Bag，紧急撤离包）：35L / 8.5kg，3分钟内可带走。
- **车载/旅行 BOB**：模块化设计，常驻车内或旅行使用。

### 1. 家用 BOB 详细清单（35L 背包）

**背包**：犸玎拓普“黑旋风”35L（910D考杜拉面料，低调耐磨）

**主要分类内容**：

- **工具/信息**：
  - 防水地图
  - 《怀斯曼生存手册》
  - 多功能钳（城市环境用）
  - 手电系统：傲雷行者Pro + 徒步头灯 + MOLLE副手电
  - 10000mAh 二合一移动电源
  - 全球波段应急收音机（太阳能/手摇充电，带SOS功能）

- **食品/水/火**：
  - 72小时压缩干粮 + 饮用水（5年保质期）
  - 电解质盐
  - 索耶水过滤器
  - 防风打火机 + 风暴火柴 + 应急蜡烛

- **起居/医疗**：
  - 快干换洗衣物
  - 三合一雨披（240g，轻便，可作天幕/地席，PU4000+防水）
  - 杜邦棉可穿式斗篷（可作斗篷/睡袋/被子）
  - 迪卡侬Aptonia急救包（增配：救生毯、净水片、生理盐水、碘伏、布洛芬、氯雷他定、蒙脱石散、云南白药膏等）
  - 洗漱包（一次性内衣裤、湿巾、压缩毛巾、口罩、垃圾袋）

### 2. 车载/旅行 BOB（模块化方案）

**载体**：Tomtoc T21S1 胸包（常驻车内或行李箱，旅行时可作随身包）

**内部模块**：

- PSK 生存盒（极简防水盒）
- EDC 小包
- 犀牛救援鹰眼急救包

特点：模块化设计，可快速腾空部分模块放入卡包、相机等日常物品。

### 3. PSK 生存盒（Personal Survival Kit，个人生存盒）

- 使用 MUJI 收纳盒 + 考杜拉异刃虎防水袋，极简防水设计。
- 建议准备**2个**（分别放家用BOB和车载BOB），在紧急抛弃大背包时仍能携带核心物资。
- 城市环境下省略鱼钩、针线等野外物品（与急救包功能重叠）。

### 4. EDC 小包（Every Day Carry，日常随身携带）

核心原则：围绕**刀、光、火、电、药**五要素，体积小巧，可放入裤子左口袋。

**主要物品**：

- **刀**：纳拓S11 Pro / 洛森M2 / 维氏瑞士军刀卡（注意安检，无主刀）
- **光**：威沃德K3 多功能手电（800流明，IP65，远射/RGB/点烟器/红激光/UV/磁吸）
- **火**：K3 点烟器功能
- **电**：Type-C 短线 或 小米金沙江磁吸5000mAh 移动电源（超薄6mm）
- **药**：创口贴、酒精片、碘伏棉签、解酒片、氯雷他定（针对过敏性鼻炎）

**可选物品**：AirTag、AirPods Pro、U盘、擦镜纸、牙线、口喷、鼻通、圆珠笔、指甲剪、手机支架、迷你撬棍、隐形眼镜、香水小样、LOOP SK09-LOOPDOT 等小玩具。

### 6. 装备管理工具

作者使用**多维表格**管理所有物品：

- 记录位置、保质期、重量、金额
- 支持保质期自动提醒（颜色标记：>90天绿色、30-90天黄色、0-30天橙色、过期红色）
- 使用 Gemini Pro 3 编写保质期计算函数
- 可分享链接、快速找出最重物品等

### 总结与作者建议

- 强调“**灰人**”风格：低调、实用、不引人注目。
- 采用**分层 + 模块化**思路：家用BOB 较重（主力），车载BOB 较轻（补充），PSK + EDC 作为核心可抛弃模块。
- 优先准备 **刀/光/火/电/药** 五要素。
- 建议普通人按72小时城市标准储备应急物资，重点关注保质期管理和实际使用场景。
