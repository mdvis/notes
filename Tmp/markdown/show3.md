git show` 是 Git 中非常强大且常用的一个命令，你可以把它看作是 Git 仓库的“放大镜”**。它的主要作用是**查看各种 Git 对象（主要是提交 commit，也可以是标签 tag、树 tree 或文件 blob）的详细信息和内容差异。

以下是 `git show` 命令在日常开发中最核心的精要用法：

### 1. 默认行为：查看最新提交

如果你不加任何参数，直接运行：

```bash
git show

```

它会默认展示当前分支的最新一次提交（即 `HEAD`）的详细信息，包括：作者、日期、提交说明（commit message），以及该次提交所引入的**具体代码差异（diff）**。

### 2. 查看特定提交的代码变更

这是最常用的场景，当你需要知道某次历史提交具体改了什么代码时：

```bash
git show <commit-hash>

```

- **示例:** `git show 3a1f8b4` （只需输入 commit 哈希值的前几位即可）。
- **游标用法:** 你也可以用 `HEAD` 的相对路径，例如 `git show HEAD~1`（查看上一次提交）或 `git show HEAD~2`（查看上上次提交）。

### 3. 查看特定提交中的特定文件

如果你只想看某次提交中**某个具体文件**的修改差异，而不是所有文件的差异：

```bash
git show <commit-hash> -- <file-path>

```

- **示例:** `git show HEAD~1 -- src/main.js` （查看上一次提交中 `src/main.js` 文件的变化）。

### 4. 穿越时空：查看某次提交时文件的完整内容

有时候你不想看 Diff（差异），而是想直接查看**在过去某个版本时，某个文件的完整代码长什么样**。这个功能非常实用：

```bash
git show <commit-hash>:<file-path>

```

- **示例:** `git show 3a1f8b4:package.json` （直接在终端输出 `3a1f8b4` 这次提交时的 `package.json` 的全部内容）。
- _注意：哈希值和文件路径之间用冒号 `:` 连接，且没有空格。_

### 5. 精简与定制输出 (Log 格式化)

如果你觉得默认输出的代码 Diff 太长，可以使用参数来精简信息：

- **只看提交信息，不看代码 Diff：**

```bash
git show -s <commit-hash>

```

- **只看哪些文件被修改了，不看具体改了哪一行：**

```bash
git show --name-only <commit-hash>

```

- **查看修改了哪些文件，以及增加/删除了多少行（统计信息）：**

```bash
git show --stat <commit-hash>

```

### 6. 查看标签 (Tag) 的详细信息

当你发布了新版本并打上了标签，可以使用它来查看标签的附注信息以及它指向的提交：

```bash
git show v1.0.0

```

---

**💡 总结对比：`git show` vs `git log**`

- **`git log`** 是一张**宏观的列表**，用来查看“历史记录的长河”，告诉你发生了哪些提交。
- **`git show`** 是一张**微观的照片**，用来深入剖析“某一次特定提交”，告诉你那次提交具体改动了什么。
